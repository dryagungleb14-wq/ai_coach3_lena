# Инструкция по работе с AI Coach

Сервис AI Coach предназначен для анализа звонков менеджеров: расшифровка разговора и оценка по чек-листу. Звонки можно загружать вручную или подтягивать автоматически из Telphin.

---

## 1. С чего начать

- Откройте главную страницу сервиса.
- Убедитесь, что вверху отображается зелёный статус: «Бэкенд доступен». Если подключения нет — проверьте интернет и сообщите ответственному за настройку.
- Дальше можно либо загрузить аудио вручную, либо настроить выгрузку из Telphin и синхронизировать звонки.

---

## 2. Загрузка звонков вручную

1. На главной странице найдите блок **«Загрузить аудио»**.
2. Выберите один или несколько аудиофайлов (поддерживаются распространённые форматы).
3. При необходимости укажите:
   - имя менеджера;
   - дату звонка;
   - идентификатор звонка (если есть).
4. Нажмите загрузку. Файлы появятся в списке, после чего автоматически запустится **расшифровка** и **оценка по чек-листу**.
5. Прогресс отображается в блоке «Анализ в процессе». По окончании звонки появятся в «Истории звонков» и на «Дашборде».

---

## 3. Выгрузка звонков из Telphin

Если у вас настроена интеграция с Telphin, звонки можно не скачивать вручную, а подтягивать по кнопке.

### 3.1. Настройка операторов (один раз)

1. Перейдите в раздел **Telphin** (кнопка «Telphin» на главной).
2. Нажмите **«Загрузить список добавочных»**. Появится таблица всех добавочных (внутренних номеров) вашей АТС.
3. В таблице для каждого номера:
   - включите галочку **«Мониторить»** у тех операторов, чьи звонки нужно анализировать;
   - в колонке **«Имя менеджера»** введите ФИО или имя (так оно будет отображаться в отчётах).
4. Изменения сохраняются автоматически при снятии/установке галочки и при выходе из поля «Имя менеджера».

**Важно:** без выбранных операторов (хотя бы одна галочка «Мониторить») кнопка «Синхронизировать» будет неактивна.

### 3.2. Запуск синхронизации

1. В разделе Telphin задайте период:
   - **Дата начала** и **Дата окончания** — за какой период брать звонки (если не указать — по умолчанию последние сутки);
   - **Мин. длительность (сек)** — звонки короче этой длительности не загружаются (по умолчанию обычно 120 секунд).
2. Нажмите **«Синхронизировать»**.
3. Синхронизация идёт в фоне. Статус и количество найденных/импортированных/пропущенных звонков отображаются в блоке «Последняя синхронизация» и в «Истории синхронизаций».
4. Загруженные звонки автоматически расшифровываются и оцениваются по чек-листу, как при ручной загрузке.

**Что попадает в выгрузку:** только звонки выбранных операторов (добавочных с галочкой «Мониторить»), с длительностью не меньше указанной и только ответленные (ANSWER). Уже ранее импортированные звонки не дублируются.

---

## 4. История звонков и фильтры

- Раздел **«История звонков»** — полный список обработанных звонков с пагинацией.
- Можно отфильтровать по **менеджеру**, **дате начала** и **дате окончания**, затем нажать «Применить».
- В таблице видны: менеджер, дата, длительность, оценка, наличие пометки «Требуется проверка». Клик по строке открывает карточку звонка.

---

## 5. Карточка звонка

В карточке доступны:

- **Транскрипция** — текст разговора.
- **Оценка по чек-листу** — баллы по критериям, итоговая оценка, комментарии, нарушения.
- **Особые обстоятельства** — если система определила обстоятельства (например, клиент отказался отвечать, технические проблемы), они отображаются здесь; такие звонки помечаются «Требуется проверка».
- При необходимости можно запустить **повторную проверку** (переоценку по тому же чек-листу).

---

## 6. Дашборд

На **«Дашборде»** отображаются сводные данные по звонкам: распределение оценок, менеджеры, периоды. Используйте его для общей картины по качеству звонков.

---

## 7. Критерии оценки

Раздел **«Критерии оценки»** содержит:

- **Общие правила** оценки звонков.
- **Чек-лист по этапам** — какие критерии проверяются и как выставляются баллы (макс. / срединный / мин.).
- **Особые обстоятельства** — при каких ситуациях звонок помечается для ручной проверки и как они влияют на оценку.

Именно по этому чек-листу и правилам система оценивает каждый загруженный или подтянутый из Telphin звонок.

---

## 8. Экспорт

- На **главной** и в **«Истории звонков»** доступна кнопка **«Экспорт в CSV»**.
- Экспортируются данные по звонкам с учётом текущих фильтров (менеджер, даты). Файл можно открыть в Excel или Google Таблицах для отчётности.

---

## 9. Пометка «Требуется проверка»

Если система обнаружила особые обстоятельства (например, отказ клиента отвечать на вопросы, технические проблемы, прерванный разговор), звонок помечается **«Требуется проверка»**. Эта пометка видна:

- в общем списке звонков (в истории и на главной, где отображаются последние);
- при открытии карточки звонка.

Такие звонки стоит просматривать вручную, чтобы убедиться, что оценка учла контекст и не занижена из-за обстоятельств, не зависящих от менеджера.

---

## 10. Краткая схема работы

| Действие | Где | Результат |
|----------|-----|-----------|
| Загрузить аудио вручную | Главная → Загрузить аудио | Файлы загружены → расшифровка → оценка по чек-листу |
| Настроить операторов Telphin | Telphin → Загрузить список добавочных | Выбраны номера и имена менеджеров для выгрузки |
| Подтянуть звонки из Telphin | Telphin → даты и длительность → Синхронизировать | Звонки выбранных операторов за период загружены и проанализированы |
| Посмотреть все звонки и отфильтровать | История звонков | Список с фильтрами по менеджеру и датам |
| Посмотреть расшифровку и оценку | Клик по звонку → карточка | Транскрипция, баллы, особые обстоятельства |
| Понять, по чему оцениваем | Критерии оценки | Чек-лист и правила |
| Скачать отчёт | Главная или История → Экспорт в CSV | Файл для отчётности |

---

Если что-то не работает (нет подключения к бэкенду, ошибка при синхронизации Telphin, не запускается анализ) — зафиксируйте текст ошибки и при необходимости сделайте скрин, и передайте ответственному за сервис.
